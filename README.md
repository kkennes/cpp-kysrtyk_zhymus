## 📌 Жоба туралы
Бұл репозиторийда C++ бағдарламалау тіліндегі **массивтер мен кірістірілген құрылымдар (`struct`)** негізінде студенттердің сессия нәтижелерін есептейтін бағдарламаның бастапқы коды орналастырылған.

### Негізгі мүмкіндіктері:
* **Динамикалық жадыны басқару:** Студенттер санына ($n$) қарай жедел жадыны `new[]` арқылы бөлу және жұмыс соңында `delete[]` арқылы толық тазарту.
* **Кірістірілген құрылымдар моделі:** `Subject` (пән атауы мен бағасы) және `Student` (аты-жөні, ID нөмірі, 3 пән массиві, орташа GPA) құрылымдарын біріктіру.
* **Енгізуді қорғау (Валидация):** Студенттер санының оң бүтін сан болуын және пән бағаларының `0–100` аралығында енгізілуін қатаң тексеру (мәтіндік қателерді `cin.clear()` / `cin.ignore()` арқылы өңдеу).
* **Автоматты есептеу және талдау:** Әр студенттің орташа балын ($GPA = \frac{B_1 + B_2 + B_3}{3}$) есептеу, кесте түрінде шығару (`iomanip`) және ең жоғары GPA иегер(лер)ін анықтау.
